### Library Bodium

my personal linked list library

Stack, bag, Binary search Tree and Graphs with algorithms and file utilities

an example run of binary fast_collinear:\
\
cargo run --bin fast_collinear -- bin/collinear_points/data/input20.txt

cargo run --bin graph -- bin/graphs/data/digraph9.txt 5

cargo run --bin rbt_try -- bin/data/bst40.txt geo

cargo run --bin bst_trial -- bin/data/bst40.txt geo

or run with alias as defined in .cargo/config.toml\

cargo rbt , graph, digraph, bst or collinear
